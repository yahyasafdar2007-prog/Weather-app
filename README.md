# Weather App

A weather app built with Next.js and TypeScript that shows current weather for any city.

## Features

- Search weather by city name
- Shows temperature and current conditions
- Responsive layout

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- [Name of the weather API you use]

## Run Locally

1. Clone the repo:
```bash
   git clone https://github.com/yahyasafdar2007-prog/weather-app.git
   cd weather-app
```
2. Install dependencies:
```bash
   npm install
```
3. Create a `.env.local` file in the root and add your own API key:

4. Start the dev server:
```bash
   npm run dev
```
5. Open http://localhost:3000
